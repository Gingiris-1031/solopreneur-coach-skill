# OPC Coach｜Solopreneur Coach 一人公司 AI 教练

**帮助你开始一人业务的 AI Skill · by Gingiris**

[English](README.md) | [简体中文](README.zh-CN.md)

> 从能走的一小步开始，逐渐建立自己的一人业务。

**Gingiris OPC Coach 是 Solopreneur Coach 的中文搜索名称，两者为同一个 Skill。** [中文入门页](https://tools.gingiris.com/zh/skills/opc-coach/)

Solopreneur Coach 帮助想尝试一人创业的人，从已有经验出发做一个小尝试、验证真实需求，逐步走向第一份付费交付。说说当前处境，拿到可用草稿，做一个能承担的动作，再带着实际结果回来调整。

**当前状态：**v0.1.0 公开预览版，中英文内容齐备。尚未完成目标用户测试或商业效果验证，示例为虚构。

## 适合谁

有经验，但不知道别人会为什么付费；有想法，但能投入的时间不多；或已经有人找你帮忙，需要确定范围、报价与交付。

专业服务是目前支持最完整的路径。产品、内容方向也可以用来选择起点和验证需求，但本版不宣称覆盖所有业务类型的完整经营。不需要先辞职或注册公司才能探索想法。

## 从一句话开始

让 AI 加载 Skill 后，可以直接说：

```text
请使用 gingiris-solopreneur-coach。我想尝试做一人业务，但还不知道从哪里开始。
请一次问我一个容易回答的问题，并帮我准备一个真正能做的小动作。
```

已经有具体问题，也可以直接进入：

| 现状 | 可以复制的开场 |
| --- | --- |
| 有经验，无服务 | 我做了五年设计，请从我真正做过的事里，帮我找到一项有边界的服务。 |
| 有想法，时间少 | 我想做简历工具，每周只有两小时，帮我先验证最重要的假设。 |
| 有意向客户 | 有人找我帮忙做内容，请帮我在报价前说清楚交付什么。 |
| 做完第一单 | 客户满意，但我花了太多时间。帮我复盘下一单需要改什么。 |
| 卡住 | 上次动作我没做，今天只有十五分钟，帮我把下一步缩小。 |

入口和阶段参考均提供中英文。Coach 跟随你的语言，随时可以要求切换。你可以说不知道、跳过、纠正假设，或直接要求起草。

## 第一次聊完应当得到什么

一两轮必要澄清后，得到一个暂定的待验证问题、符合条件的小动作，以及邀约、访谈问题或服务说明等可用材料。Coach 应说明回来带什么证据，以及什么结果会改变下一步。

计划是起手材料，真实反馈来自对话之外的人和事件。

## 一段使用示例

*虚构教学示例，不承诺收入或结果。*

**你：**我做了五年设计，每周有三小时，不知道能卖什么。

**Coach：**最近一次别人因为设计问题找你帮忙，具体是什么事？

**你：**朋友店里的菜单太乱，我帮她整理过。

**Coach：**这给了我们一个可以试的方向：让菜单信息更清楚。目前还不知道其他店主是否愿意为这个问题付费。先用约二十分钟整理一个有权分享的前后对比，下面是你可以自行决定是否发给相关店主的消息：

> 我最近在了解菜单设计中的常见问题。你店里有没有顾客总要追问、需要反复解释的菜单内容？如果有，能不能讲一次最近发生的情况？暂时不用决定是否购买设计服务。

**你下次回来：**对方有这个问题，但觉得不值得花钱。

**Coach：**我们知道问题存在，但付费意愿还没出现。先理解原因，再决定改服务、换一个客户场景，或者暂时放下这个方向。

## 带着证据回来

```text
继续使用 gingiris-solopreneur-coach。
上次计划做：
实际发生了什么：
对方的原话或行为（已匿名）：
现在能投入的时间：
```

没有行动也可以直接说。下一步可以缩小、澄清、推迟或暂停。开启新对话时带上之前的进度摘要；Skill 不保证跨会话记忆，也不会自动主动提醒。

## 两种不同的进展

- **学习闭环：**问题→行动→外部反馈→更新判断→下一决定。有依据地停止不合适的方向也有价值。
- **付费业务闭环：**需求→确认范围与报价→按约付款和启动→交付→验收→约定款项结清→复盘。仍需保留后续支持义务。

免费样例、称赞、首款到账和完整付费交付是不同状态，Coach 会分别记录。

## 包含什么

一个双语入口，按需进入一个双语阶段：

1. 找到起点与最小尝试。
2. 经验服务化与有限成果。
3. 需求研究与客户适配。
4. 范围、报价与采购状态。
5. 交付、验收、回款与复盘。

核心流程不需要额外 Skill 或私人文档权限。有具体增长任务时，可以选用已可用的 [Gingiris Skills](https://tools.gingiris.com/skills/)，它们没有随包安装，也不会自动安装。

## OPC Coach 常见问题

### OPC Coach 是什么？

Gingiris OPC Coach 是 Solopreneur Coach 的中文搜索名称，是一个支持中英文的一人公司 AI 教练 Skill。它通过温和设问帮助你明确当前问题，准备一个小行动，再根据真实反馈调整。

### OPC Coach 和 Solopreneur Coach 是两个产品吗？

不是。它们指向同一个 Gingiris Skill，仓库为 solopreneur-coach-skill，安装标识为 gingiris-solopreneur-coach。OPC 在这里指 One-Person Company，不指工业通信标准。

### 没有产品，也能开始一人公司吗？

可以先从自己做过的工作与别人提出过的具体请求开始，探索一个能承担的服务或最小实验。当前不需要先做完整产品，也不要求辞职或注册公司。

### 怎样验证第一笔付费服务？

先理解客户的真实任务，明确交付范围与验收，再提出报价，按约启动、交付、验收和结清款项。免费试做验证能力，称赞表达认可，首款代表部分付款，它们都不能单独证明完整商业闭环。

### 它是否免费，是否保证收入？

Skill 文本按 MIT 许可证开放，运行所用模型或 AI 工具可能收费。不保证成交或收入；当前为 v0.1.0 公开预览版，尚未完成目标用户效果验证。

### 安装后会自动记住进度和提醒我吗？

不保证。请保存进度摘要，换对话时带上；主动提醒需要平台支持和明确设置。只需提供必要且尽量匿名的信息，数据处理取决于你使用的 AI 平台。
