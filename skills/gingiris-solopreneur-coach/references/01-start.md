# Find a starting point / 找到起点

## English

Use when the user has no chosen direction or cannot fit an experiment into life. Start from one recent event: someone requested help, a task went well, or the user noticed an expensive workaround. If motivation matters, ask what they hope this experiment changes in their work or life. Do not collect a full personal history.

1. Separate personal contribution from employer brand, team, tools, and budget. Identify what the user can independently repeat or learn within their limits.
2. Offer at most two plausible directions based on actual evidence. Compare ability, access to relevant people, dependencies, effort, and interest. No evidence? Propose an exploration action rather than assigning an identity.
3. Choose the main unknown: demand, capability, willingness to pay, or repeatability. Match the test to that unknown. A sample tests capability; a conversation explores a task; a scoped purchase tests a specific offer.
4. Draft the needed asset now. Suggest an affordable first action, often 15–30 minutes, and an agreed or provisional observation window. Explain what a positive, negative, or missing response would mean.

Service: test one bounded result. Product: validate one job or manually simulate one workflow before a full build. Content: test whether a specific audience uses a useful piece; views alone do not show purchase intent. Do not redirect everyone into consulting.

Carry-forward template:
```text
Goal and constraints:
Current question and chosen direction:
Known evidence / assumptions:
Artifact prepared:
Next real-world action and estimated effort:
Observation window / continue, change, or stop signal:
Actual result and next decision:
Order status, if applicable:
```

If exhausted or time-constrained, reduce to selecting one example or drafting one sentence. If waiting for an external response, preserve the waiting state. A break is optional; do not require streaks or rewards.

## 中文

适用于尚未选方向或无法把尝试放进生活的人。从最近一件事开始：别人找过什么帮助、哪次任务做得好、发现了什么费力的替代办法。动机影响判断时，问这次尝试希望改变工作或生活中的什么，不收集完整人生史。

1. 分清个人贡献与原公司品牌、团队、工具、预算，找到能独立复现或在条件内学会的部分。
2. 根据证据最多提出两个方向，比较能力、能接触的人、依赖、投入和兴趣。没有证据就给探索动作，不替用户定义身份。
3. 选择主要未知：需求、能力、付费或重复性。样例检验能力，沟通了解真实任务，有范围的购买检验具体报价。
4. 当场制作所需材料。建议可承担的起手动作，通常可从15—30分钟开始，给约定或暂定观察窗口，解释肯定、否定和没回复分别意味着什么。

服务方向验证一个有限成果；产品方向先验证一个任务或人工模拟流程，再考虑完整开发；内容方向看具体受众是否使用有价值的内容，浏览量不代表付费意愿。不把所有人转向咨询。

接续模板：
```text
目标与约束：
当前问题与所选方向：
已有证据 / 假设：
已准备的材料：
下一现实动作与预计投入：
观察窗口 / 继续、调整或停止的信号：
实际结果与下一决定：
订单状态（如有）：
```

精力或时间不足时，缩到选一个案例或写一句说明；等待外部反馈时保留等待状态。休息和小奖励可选，不要求连续打卡。
